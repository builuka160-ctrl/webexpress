# WebExpress — сайт + три демо-ниши

Статика без сборщика: открывается из файловой системы, деплоится копированием папки
в web-root (nginx / Vercel / Netlify — без настроек).

```
index.html                      лендинг WebExpress (v8 из архива + живые ссылки на демо)
Калькулятор_..._Tilda_Wix_1.html  отдельная страница калькулятора (из архива, без изменений)
favicon.ico, *.png              иконки (из архива)
demo/
  kafejnica/                    GRAIN & ROAST — кофейня и пекарня
  detailing/                    NORDIC DETAILING — детейлинг-центр
  dental/                       ESTETIKA DENTAL — стоматология
  previews/                     скриншоты первых экранов для карточек в блоке «Демо-ниши»
_build/                         НЕ деплоить: скрипты генерации, сырые PNG, исходные ролики
```

## Язык

Латышский — основной. Он вшит прямо в разметку лендинга (все элементы с
`data-i18n` отдают латышский текст), а не подставляется скриптом после загрузки,
поэтому русского текста не мелькает. Переключатель RU/LV берёт вторую версию из
того же словаря.

Демо-сайты и калькулятор стартуют с латышского и помнят выбор в `localStorage`;
их рантайм переводит текстовые узлы сразу на месте, в конце `<body>`, а не по
`DOMContentLoaded` — по той же причине.

## Что починено

- **Шапка перекрывала секцию `#arch-track`.** Закреплённый блок висел на
  `top: 0`, из-за чего бейдж и заголовок уезжали под панель. Секции отсчитываются
  от `--header-h`.
- **Слои в 3D-разборе налезали друг на друга.** Разлёт увеличен, а вся стопка
  масштабируется под доступную высоту, чтобы на низких экранах не обрезалась.
  Добавлена подсказка «Листайте вниз — слои разложатся», она гаснет на 20%
  прокрутки секции.
- **На демо-сайтах не было навигации на телефоне.** Ссылки были спрятаны
  `display: none` без замены — добавлен бургер с выпадающим меню.
- **Горизонтальная прокрутка на детейлинге.** `overflow-x` стоял только на
  `body`; фото машины с отрицательным отступом растягивало `html` на 35px.
- **Зуб в шапке стоматологии выглядел грибом.** У 3D-рендера коронка была втрое
  шире штифта и с «пустой» верхушкой. Заменён на вектор из
  `_build/tooth_svg.py` с анатомическими пропорциями.
- Убраны непроверяемые обещания: `LCP < 0.8s`, `+30-40% к доходимости`,
  `100% личный сервер`, название дистрибутива. Зелёные точки-индикаторы убраны
  везде.

Блок `#portfolio` («Специально разработанные демо-ниши»):

## Демо-сайты

Три вымышленных бизнеса — это собственные демо студии, а не работы заказчиков.
Каждый сайт: один файл `index.html` (CSS и JS внутри), папка `assets/`, никаких
зависимостей и CDN, кроме Google Fonts.

| | Кофейня | Детейлинг | Стоматология |
|---|---|---|---|
| Референс | CAFE LUMO | Clean Premium Car | Dentiva |
| Шрифты | Manrope + Inter | Montserrat + Inter | Inter (200–800) |
| Палитра | `#F6EFE4 #C79F76 #3F332B` | `#161618 #CE2425 #F8F8F8` | `#B5CFDC #EDF2F5 #17191B` |
| Фишка | меню с ценами и бронь стола | калькулятор + «до/после» | 3D-хиро, счётчики, прайс |
| Вес | ~880 КБ | ~2,1 МБ (1,25 МБ — видео) | 240 КБ |

Общее для всех трёх:

- мобильный-first, проверено на 390 px;
- семантическая вёрстка, alt по-русски, фокус-стили, `prefers-reduced-motion`;
- JSON-LD (`CafeOrCoffeeShop`, `AutoWash`, `Dentist`), OG-теги, favicon инлайном;
- `robots: noindex, follow` — демо не должны конкурировать в выдаче с реальными
  клиниками и мойками Резекне;
- формы ничего не отправляют и честно пишут об этом; на рабочем сайте это
  WhatsApp deep link;
- бейдж «Демо-концепт WebExpress» и строка в подвале о том, что бизнес вымышленный.

## Скролл-видео (детейлинг)

Секция высотой 280vh, внутри `position: sticky`; прогресс прокрутки маппится в
`video.currentTime` через `requestAnimationFrame`. Ни `autoplay`, ни `loop`:
страница стоит — кадр стоит, скролл вверх отматывает назад. На мобильных
(<768 px) и при `prefers-reduced-motion: reduce` видео не грузится вообще,
показывается статичный кадр (`*-poster.webp`).

Кодирование: `-g 1 -keyint_min 1 -sc_threshold 0` (каждый кадр ключевой, иначе
скраб идёт ступеньками) + `+faststart`. Ролик ≤ 1,25 МБ.

В кофейне этот блок убран: `<video>`, скраб-скрипт и 280vh секции удалены,
остался статичный кадр обжарки с текстом.

## Как открыть

```bash
python3 _build/serve.py
# http://127.0.0.1:8099/            — лендинг
# http://127.0.0.1:8099/demo/dental/ — демо
```

`_build/serve.py` — обычная статика плюс byte-range (без него Chrome не
перематывает видео). Из `file://` страницы открываются, но скраб работать
не будет.

## Что проверено (17.09.2026)

Проверялось headless-Chrome'ом на локальном сервере с поддержкой Range
(`_build/` содержит скрипты):

- `errtest.py` — ни одной JS-ошибки на четырёх страницах (нашёл и починил
  реальную: кусок CSS попал внутрь `<script>` детейлинга и убивал калькулятор);
- `scrubtest.py` — видео отдаёт `duration=6.00`, прогресс секции считается
  верно (`p=0.75` на 75% прокрутки), `currentTime` двигается от скролла;
- мобильный фоллбэк: при 390px секция получает класс `static`, `<video>`
  удаляется из DOM — ролик на телефон не качается вообще;
- ползунок «до/после»: `--split` меняется на 20% и 80%;
- калькулятор: внедорожник + DETAILING + керамика = 333 € (95×1.3 + 190×1.1);
- формы на всех трёх демо: пустая — ошибка про имя и телефон, заполненная —
  текст «заявка принята (демо)»;
- битых ссылок и внешних `<img src>` нет.

Досмотреть глазами стоит только сам скраб видео: в headless-Chrome перемотка
не доигрывается (виртуальное время не двигает медиа-часы), а вкладка под
расширением была фоновой — Chrome в фоне не грузит видео. Открой любую из
двух страниц в обычном окне и покрути колесо.

Скриншоты: `~/Pictures/webexpress-demo/`.

```bash
python3 _build/serve.py   # http://127.0.0.1:8099 — статика с поддержкой Range
# обычный python3 -m http.server не отдаёт byte-range, и видео-скраб на нём не перематывается
```
