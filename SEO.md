# SEO: что сделано в коде и что нужно сделать руками

Цель — вывести сайт в органическую выдачу по коммерческим запросам:
«заказать сайт», «создание сайтов», «разработка сайта под ключ», «купить сайт»,
«сколько стоит сайт», плюс латышский кластер «mājas lapas izstrāde»,
«pasūtīt mājaslapu».

Сразу о честных ожиданиях: код отвечает примерно за половину результата.
Вторая половина — возраст домена, ссылки и поведенческие факторы. Ни один
набор мета-тегов не ставит сайт на первое место за неделю; по конкурентным
коммерческим запросам в Латвии реалистичный горизонт — **2–4 месяца** до
первых позиций в топ-10 и дольше по высокочастотным запросам без ссылок.
Ниже разделено: что уже в репозитории и что зависит от вас.

## 1. Сделано в репозитории

### Отдельная русская страница `/ru/`

Главное изменение. Раньше русский текст подставлялся скриптом поверх
латышского **на том же URL**. Для поиска это означало: у русских запросов нет
ни одной страницы-ответа — ни своего адреса, ни своего `<title>`, ни своего
canonical. Запрос «заказать сайт» было нечем ранжировать.

Теперь `/ru/index.html` — статическая страница: русский текст лежит прямо в
HTML, у неё свой заголовок, описание, canonical и микроразметка.

Собирается из `index.html` скриптом `_build/make_ru.py` — латышский лендинг
остаётся единственным источником правды.

```
python3 _build/make_ru.py     # пересобрать /ru/ после правок index.html
python3 _build/apply_seo.py   # обновить JSON-LD в index.html
python3 _build/make_sitemap.py
```

**Важно:** после любой правки текста в `index.html` пересоберите `/ru/`,
иначе языковые версии разъедутся.

### Заголовки под коммерческие запросы

| Страница | `<title>` |
|---|---|
| `/` | Mājas lapas izstrāde Latvijā — pasūti mājaslapu no 250 € \| WebExpress |
| `/ru/` | Заказать сайт под ключ — создание сайтов от 250 € \| WebExpress |
| `/kalkulators.html` | Сколько стоит сайт: калькулятор расходов на 10 лет \| WebExpress |

### hreflang

На обеих страницах прописаны `lv`, `ru` и `x-default`, плюс те же
альтернативы продублированы в `sitemap.xml`. Переключатель RU/LV стал
обычными ссылками (`<a href>`) вместо JS-кнопок — робот их видит и обходит.

### Микроразметка Schema.org

Один `@graph` в `<script type="application/ld+json">` на каждой странице:

- `ProfessionalService` / `WebDesignBusiness` — название, адрес (Резекне),
  координаты, телефон, часы работы, языки, `priceRange`;
- `Service` + `OfferCatalog` — три тарифа (250 / 350 / 550 €) и два плана
  хостинга (5 / 25 € в месяц) со сроками исполнения;
- `FAQPage` — вопросы из блока FAQ плюс два новых: «сколько стоит» и
  «за сколько дней». Это шанс занять расширенный сниппет в выдаче;
- `WebSite` и `WebPage`.

Источник данных — `_build/seo.py`. Правки цен и текстов вносите туда, потом
`apply_seo.py` и `make_ru.py`.

Проверить: [Rich Results Test](https://search.google.com/test/rich-results).

### Секция «Что можно заказать» (`#services`)

Раньше на странице не было текста, отвечающего на сам запрос. Добавлен
видимый блок из четырёх карточек с ценами: лендинг, сайт-визитка,
корпоративный сайт с SEO, сайт с хостингом под ключ — и абзац с географией
(Резекне, Рига, Даугавпилс). Никаких скрытых текстов и подмены контента для
роботов: то, что видит Google, видит и человек.

### Технические файлы

- `robots.txt` — открыт весь сайт, закрыты `/_build/` и архивы `.zip`,
  указан sitemap;
- `sitemap.xml` — три индексируемых адреса с языковыми альтернативами.
  Демо-концепты в карту **не включены**: у них в `<head>` стоит
  `noindex` (это вымышленные заведения с вымышленными адресами, им не место
  в поиске), и включать их в sitemap означало бы получить ошибку в Search
  Console;
- `og-image.png` (1200×630) — раньше был прописан в мета-тегах, но
  отсутствовал: превью ссылки в WhatsApp и Telegram было битым.
  Пересобрать: `_build/make_og.sh`, шаблон — `_build/og_image.html`;
- `kalkulators.html` — файл переименован из
  `Калькулятор_стоимости_и_сравнение_HTML_vs_Tilda_Wix_1.html`. Кириллица в
  имени файла превращается в нечитаемый URL с процентами при копировании
  ссылки. Добавлены canonical, описание и Open Graph.

### Мелочи

- `alt` у картинок переведены по языку страницы (на латышской были русские);
- подвальному логотипу проставлены `width`/`height` и `loading="lazy"` —
  меньше сдвига макета (CLS учитывается в Core Web Vitals);
- `meta robots` с `max-snippet:-1` и `max-image-preview:large` — разрешает
  Google показывать длинный сниппет и крупную картинку;
- `geo.*` мета-теги с привязкой к Резекне.

## 2. Что нужно сделать руками (без этого код не сработает)

Это не опционально. По коммерческим запросам сайт без внешних сигналов не
поднимется, каким бы аккуратным ни был HTML.

### Сразу после деплоя

1. **Google Search Console** — https://search.google.com/search-console
   Подтвердить домен, отправить `https://webexpress.lv/sitemap.xml`,
   запросить индексацию `/` и `/ru/` через «Проверка URL».
2. **Bing Webmaster Tools** — https://www.bing.com/webmasters
   Импортируется из Search Console в два клика. Bing даёт трафик в Латвии.
3. **Проверить, что сервер отдаёт `/ru/`** — каталог с `index.html` должен
   открываться по адресу со слешем на конце. На nginx это `try_files`
   по умолчанию, на Netlify и Vercel работает из коробки.
4. **HTTPS и один канонический хост.** Все варианты (`http://`, `www.`)
   должны 301-редиректить на `https://webexpress.lv`. Дубли хостов размывают
   сигналы.

### Google Business Profile — самый быстрый источник заявок

Для локального бизнеса карточка в Google Картах часто приносит первые
обращения раньше, чем сайт выйдет в органику.

- Создать профиль на Резекне, категория «Веб-дизайнер» / «Tīmekļa dizaineris»;
- указать сайт `https://webexpress.lv/`, телефон +371 22 441 603, часы работы —
  те же, что в микроразметке (пн–сб 09:00–20:00), иначе Google видит
  расхождение;
- добавить 5–10 фотографий работ;
- **собирать отзывы** — это главный фактор ранжирования в локальной выдаче.
  Просите каждого клиента после сдачи сайта.

### Ссылки и упоминания

Домен новый, ссылочная масса нулевая. Что даёт результат без бюджета:

- каталоги латвийского бизнеса: `firmas.lv`, `zl.lv`, `company.lv`;
- профили с активной ссылкой: Instagram, Facebook, LinkedIn, Telegram-канал;
- Behance или Dribbble с кейсами и ссылкой на сайт;
- локальные группы и форумы Резекне и Латгалии — без спама, по делу.

Не покупайте ссылки пачками на биржах: для молодого домена это риск
попасть под фильтр, а не ускорение.

### Контент, которого не хватает

Текущий сайт — один лендинг. Один URL может ранжироваться максимум по
нескольким запросам. Чтобы охватить кластер, нужны отдельные страницы, у
каждой — свой запрос в заголовке:

| Страница | Целевой запрос |
|---|---|
| `/ru/zakazat-lending/` | заказать лендинг |
| `/ru/sajt-vizitka/` | сайт-визитка под ключ |
| `/ru/skolko-stoit-sajt/` | сколько стоит сделать сайт |
| `/ru/sajt-dlya-salona-krasoty/` | сайт для салона красоты |
| `/ru/sajt-dlya-avtoservisa/` | сайт для автосервиса |
| `/lv/majas-lapas-izstrade-rezekne/` | mājas lapas izstrāde Rēzeknē |

Плюс блог с разборами: «сколько на самом деле стоит Tilda за 5 лет»,
«почему Instagram не заменяет сайт». Под это уже есть калькулятор — на него
удобно ссылаться из статей.

Это самая трудоёмкая часть и одновременно та, которая даёт основной прирост.

### Скорость

Замерить на https://pagespeed.web.dev для `/` и `/ru/`. Известные места:

- `kalkulators.html` тянет Tailwind с `cdn.tailwindcss.com` — это компилятор
  в браузере, он не для продакшена. Собрать статический CSS, как на лендинге;
- шрифты грузятся с Google Fonts — при желании положить `.woff2` рядом
  с сайтом и подключить локально, это убирает два внешних соединения;
- `index.html` весит 214 КБ, часть — логотипы в base64. Включите gzip или
  brotli на сервере, это снимает большую часть.

## 3. Как проверять результат

- Search Console → «Эффективность»: показы и позиции по запросам. Первые
  показы обычно появляются через 2–4 недели после индексации;
- Search Console → «Покрытие»: обе страницы должны быть «Проиндексировано»;
- `site:webexpress.lv` в Google — быстрая проверка, что в индексе;
- Rich Results Test — что FAQ и организация распознаются.

Позиции меряйте по конкретным запросам в режиме инкогнито с латвийской
геолокацией, а не «на глаз»: поиск подстраивается под историю.
