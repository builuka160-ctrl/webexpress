# PHASES — скелет сайта

Статичный HTML/CSS/JS без сборки. Открыть `index.html` в браузере.

## Файлы
- `index.html` — разметка всех блоков (hero, услуги, каталог, смета, заявка, проекты, партнёры, FAQ, контакты)
- `style.css` — только раскладка, дизайн садится поверх
- `script.js` — каталог, калькулятор, формы, переключатель языков (заглушки)
